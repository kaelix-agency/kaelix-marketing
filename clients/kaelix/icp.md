# ICP — KAELIX

> **Statut : hypothèse (v1 d'onboarding, 2026-10-16)** — à retravailler via le skill `icp` avec les données des premiers cycles (sources : grille tarifaire v2, entretien opérateur, clients signés). L'ICP décide quels mots-clés valent la peine.

## Profil d'entreprise cible

| Critère | Valeur |
|---|---|
| Taille | TPE / PME de 1 à ~20 salariés ; indépendants et professions libérales pour l'entrée de gamme |
| Secteurs | artisanat, transport/logistique, commerce et services de proximité, services B2B — les métiers « réels » sans équipe web |
| Zone | Île-de-France et Montpellier en priorité (présence physique) ; France entière à distance |
| Budget | 80-500 € HT/mois tout compris — le trou de marché entre le low-cost non crédible (<100 €) et les agences classiques (500-1 000 €+) |
| Maturité web | pas de compétence web interne ; site vieillissant (WordPress non maintenu), site plateforme bridé, ou pas de site |
| Maturité business | **PMF requis** : activité qui vend déjà (bouche-à-oreille, réseau) et veut un canal d'acquisition en ligne — pas de création d'entreprise sans clients |

## Signaux d'achat

- Site WordPress cassé, lent ou plus maintenu ; prestataire web disparu
- Dépendance totale au bouche-à-oreille et volonté d'en sortir
- Fiche Google existante mais négligée (photos, avis sans réponse)
- Concurrents locaux visibles sur Google, eux
- Événement déclencheur : déménagement, nouvelle offre, reprise d'entreprise, rachat

## Anti-ICP (on décline ou on requalifie)

- Pré-PMF (pas de ventes régulières) → d'abord vendre, ensuite se référencer
- Grands comptes / appels d'offres, besoins d'application métier complexe → sur devis, hors cœur de cible SEO
- Recherche du prix plancher absolu (<80 €/mois) → plateformes self-service
- Secteurs YMYL lourds (santé réglementée, finance) tant que la charge E-E-A-T n'est pas rentable pour l'agence

## Référence incarnée

Transports Ansquer (transport/logistique, Gennevilliers, ~10 salariés, dirigeant repreneur, zéro équipe web, bouche-à-oreille historique) : le client type, documenté dans `clients/transports-ansquer/`.
