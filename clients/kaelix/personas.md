# Personas — KAELIX

> **Statut : hypothèse (v1 d'onboarding, 2026-10-16)** — à retravailler via le skill `personas`. Invariant : un contenu = UN persona, déclaré avant production (colonne Persona de `tracking.md`).

## P1 — Le dirigeant-artisan qui n'a pas le temps

- **Qui** : patron de TPE (artisan, transporteur, commerçant), 35-60 ans, 1-15 salariés, débordé par l'opérationnel. Archétype réel : Martin (Transports Ansquer).
- **Rapport au web** : sait qu'il « devrait » ; a peut-être un site honteux ou rien ; méfiant après une mauvaise expérience (prestataire disparu, site jamais livré, abonnement opaque).
- **Ce qu'il cherche (requêtes)** : « création site internet artisan », « refaire son site d'entreprise prix », « agence web + ville », « être visible sur Google ».
- **Ce qui le convainc** : le prix lisible tout compris, l'avant/après chiffré d'un pair (le cas Ansquer), un seul interlocuteur, « faites votre métier, on s'occupe du reste ».
- **Ce qui le fait fuir** : le jargon, les devis à tiroirs, les engagements longs, les promesses de « position n°1 garantie ».

## P2 — Le gérant qui compare avant de signer

- **Qui** : gérant de TPE/PME services ou commerce, déjà en phase de choix active : il a ouvert 3 onglets (Wix/Solocal, une agence locale, un freelance).
- **Ce qu'il cherche (requêtes)** : « Wix ou agence web », « avis Simplebo », « alternative Solocal », « combien coûte un site vitrine », « agence web ou freelance ».
- **Ce qui le convainc** : une comparaison honnête par catégories (coût réel, propriété du code, maintenance, SEO natif), des références vérifiables, la possibilité de résilier.
- **Contenus pour lui** : les pages comparaison/alternatives (§6 du brief, ordre 3) et `/tarifs` — c'est LE persona des pages business.

## P3 — Le repreneur / créateur déjà lancé

- **Qui** : reprend ou développe une entreprise qui vend déjà (reprise familiale, rachat, nouvelle implantation) ; plus jeune, plus à l'aise en ligne, pressé.
- **Ce qu'il cherche (requêtes)** : « refonte site entreprise », « migrer de WordPress », « site + SEO local pack », « audit SEO gratuit ».
- **Ce qui le convainc** : la vitesse (3-5 semaines), la technique propre démontrée (Lighthouse, scores), l'audit gratuit comme premier pas sans engagement.
- **Garde-fou** : vérifier le PMF — un créateur sans ventes est hors ICP, on le dit honnêtement.
