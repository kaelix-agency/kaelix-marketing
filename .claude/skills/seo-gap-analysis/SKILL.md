# SEO Gap Analysis — méthode

## Étapes
1. **Intention** : classer la requête (info / commerciale / transactionnelle / navigationnelle / locale) à partir de la SERP réelle (Haloscan), pas de l'intuition.
2. **Concurrents SERP réels** : ce sont ceux qui occupent la page — y compris annuaires, forums, YouTube — pas les concurrents business du client.
3. **Format dominant** : identifier le format et la profondeur qui gagnent ; le contenu devra matcher (un mismatch de format est une faille en soi).
4. **Gap** : cartographier ce que couvrent les 3-5 leaders, puis chercher ce qui manque au niveau des concepts/entités (pas seulement des mots-clés).
5. **Information gain** : formuler explicitement ce que le client peut apporter d'unique (first-party du brief). C'est le critère de go/no-go.
6. **Cluster** : situer la page dans un cluster pillar + soutien ; définir le maillage prévu ; vérifier la cannibalisation (Haloscan + tracking).

## Livrable type (brief de production)
Angle, format, longueur cible, plan H2/H3, mots-clés principal + secondaires, questions FAQ, liens internes prévus, élément first-party à mobiliser, CTA.
